# ⏱️ React Stopwatch - Cronómetro con React Hooks

Este es un proyecto básico de cronómetro hecho con **React**, utilizando solo **HTML**, **JS**, **CSS** y **React por CDN**. No requiere Vite ni Webpack. Ideal para practicar `useState`, `useEffect` y `useRef`.

---

## Características

- Contador de segundos en tiempo real
- Botón para iniciar y pausar
- Botón para reiniciar
- Guardar sesiones con el tiempo actual

---

## 🧾 Cómo correrlo localmente

> 💡 Opción 1: Con Python

```bash
cd react-stopwatch
python -m http.server
```

Abrir http://localhost:8000 en el navegador.
